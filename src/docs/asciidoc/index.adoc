=== 응답 구조
모든 API는 다음과 같은 공통 응답 포맷을 따릅니다.

==== 정상 응답 (200, OK)
|====
|응답 데이터 없음|응답 데이터 존재

a|[source,json]
----
{
  "code": "0000",
  "message": "OK",
  "data": null
}
----

a|[source,json]
----
{
  "code": "0000",
  "message": "OK",
  "data": {
    "id": 1,
    "name": "sample"
  }
}
----
|====

==== 에러 응답 예시
[source,json]
----
{
  "code": "C400",
  "message": "요청 값이 올바르지 않습니다.",
  "data": null
}
----

=== 상태 코드 정의
다음은 서비스 전반에서 공통적으로 사용하는 응답 코드 및 의미입니다.

[cols="2,1,3,3"]
|====
|HttpStatus |코드 |메시지 |설명

|`200 OK` |`0000` |OK |정상 처리
|`400 BAD_REQUEST` |`C400` |요청 값이 올바르지 않습니다. |유효성 검증 실패 또는 잘못된 파라미터
|`403 FORBIDDEN` |`C403` |접근 권한이 없습니다. |인증/인가 실패
|`404 NOT_FOUND` |`C404` |요청한 리소스를 찾을 수 없습니다. |리소스 미존재
|`500 INTERNAL_SERVER_ERROR` |`S500` |알 수 없는 서버 오류입니다. |내부 예외 발생
|====
